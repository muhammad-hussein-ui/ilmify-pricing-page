# Ilmify Pricing Page

A responsive pricing page for a fictional tutorial centre, built with React, Vite and Tailwind CSS v4. It has a navbar with a hamburger menu, a hero section, three pricing cards drawn from an array of plan data, and a footer. The plans and prices are sample data.

## Run it

Needs Node.js.

```bash
git clone <git clone https://github.com/muhammad-hussein-ui/ilmify-pricing-page.git>
cd ilmify-pricing-page
npm install
npm run dev
```

Then open the address shown in the terminal, usually http://localhost:5173.

## Components

Navbar, Hero, Button, Pricing, PricingCard, Footer.
